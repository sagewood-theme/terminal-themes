# How to Install

## Alacritty
1. Download the alacritty.toml file
2. Move it to the correct folder or copy and paste it into your existing config
Windows - %APPDATA%\alacritty\alacritty.toml
Mac & Linux - ~/.config/alacritty/alacritty.toml

## Ghostty
1. Download the "config" file
2. Move it to the correct folder or copy and paste it into your existing config
Mac & Linux - ~/.config/ghostty/config

## Kitty
1. Download the kitty.conf file
2. Move it to the correct folder or copy and paste it into your existing config
Mac & Linux - ~/.config/kitty/kitty.conf

## Warp
1. Download the sagewood.yaml file
2. Move it to the correct folder or copy and paste it into your existing config
Windows - %AppData%\warp\Warp\data\themes
Mac - ~/.warp/themes
Linux - ${XDG_DATA_HOME:-$HOME/.local/share}/warp-terminal/themes

## WezTerm
1. Download the wezterm.lua file
2. Move it to the correct folder or copy and paste it into your existing config
Windows - C:\Users\<YourUsername>\.config\wezterm\wezterm.lua
Mac & Linux - ~/.wezterm.lua
